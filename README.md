# XTX Agent Translator

**English** | [中文🇨🇳](README-zh.md)

</div>

**XTX Agent Translator** is an x-to-x (e.g. zh-to-en) localhost AI agent translator for individuals and enterprises. Zero cloud upload, zero data leakage. Utilize open-source frameworks and LLMs. Customize terminology, context, and prompts — explainable, flexible, and allow you to build for your own domain-specific language system.
