# XTX 翻译家智能体

**中文🇨🇳** | [English](README.md)

</div>

**XTX 翻译家智能体**是个 x-to-x (例如中译英) 、面向个人与企业的本地 AI 翻译家智能体。零云端上传，零数据外泄。基于开源框架与大语言模型构建。支持自定义术语、上下文及提示词——具备可解释性，高灵活度，让你可以为你的垂域，打造专属的语言系统。
